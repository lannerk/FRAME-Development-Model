## Adding one / changing one

- **Opening a new feature**: directory name = the name it had in the scratch area, move the whole thing over, add a `README.md`, add a line to this table.
- **Updating an existing feature**: **change that directory directly**, add a change-log line to its `README.md`, and update "Last updated" in this table.
  **Don't open an `xxx-v2/` directory** — one feature spread over two directories means nobody later knows which to believe.

**Whether it is a new one or an update is confirmed by the Reviewer and the Requester**. The test is "**is it the same feature in the user's eyes**", not "how big is this change".
