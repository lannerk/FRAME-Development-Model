# archive/ —— 不再维护的历史

**只进不出。** 过时的规范、作废的方案、旧时代的文档搬到这里。

- **搬进来不等于删**：编号与旧引用继续有效，只是从默认阅读路径里挪出去了，所以不花任何 token。
- **不许从这里开工**：里面的东西大多建立在已经被推翻的前提上。
- 真要找某个文件的某一版，**先想想版本控制**：`git log --oneline -- <旧路径>` + `git show <sha>:<旧路径>`。

## 建议的分法

| 路径 | 是什么 |
|---|---|
| `legacy-<日期>/` | 旧结构的**全量快照**，原样保持迁移前的目录形状。要核对「以前是怎么写的」就来这里 |
| `decisions-ledger.md` | 旧决策台账原件，**一字未改**。号段文件的「详情」列指向它 |
| `memory/` | 旧的项目记忆 / 现状原件 |
| `reviews/` `deliveries/` | 旧的审查与交付记录原件 |
| `standards/` | 被角色手册与 `ai/rules/` 取代的旧规范 |
| `specs/` | 作废的技术方案 |
