# tmp/ —— 一次性工作区（**不入库**）

放**为了打包、发布、部署、搬文件而生成的一次性东西**：中转 tgz、临时脚本、抓下来的日志、对比用的副本、
以及任何「用完就没用了，因为随时能重新生成」的文件和目录。

## 四条规矩

1. **整个目录在 `.gitignore` 里，不入库。**
2. **要造一次性文件或目录，就造在这里。** 不要在别处造完再回来加 ignore 规则——
   那正是以前长出六个 `_to_delete/`（17MB / 109 个文件）的过程，最后还得需求方发话才清掉。
3. **文件名带日期**：`2026-09-16-打包/`、`2026-09-16-升级包.tgz`。没日期的下一段没人敢删。
4. **谁产生谁清，本段收尾自己删**，并在回报里写一句「本段临时件已清」。
   **不要让需求方跑 `rm`**（铁律 5）。没权限就在对话里申请一次权限，申请一次就够。

## 这里**不放**什么

| 不放 | 该放哪 | 为什么 |
|---|---|---|
| 方案、报告、审查记录、监督产出 | `claude-outputs/<角色>/` | 它们要入库——是以后复核的依据 |
| 截图、实测数据、自检输出 | `claude-outputs/developer/` 或 `shared/` | 同上，任务文件要按路径引用 |
| 编译产物、升级包、ISO | `dist/` | 也不入库，但它是产物不是草稿 |
| 「本段换下来的旧文件」 | **哪都不放** | 旧版本 git 里全有：`git log --oneline -- <文件>` + `git show <sha>:<路径>` |

**任何正式文件都不许引用 `tmp/` 里的路径**——引用了就说明它不是临时的，
按 `claude-outputs/README.md` 的转正表搬到它该在的地方。
