# 真机 / 测试环境调试链路（三个角色都要看）

> **新项目必填。** 三个角色都会上真机，这一份让他们不用每次重新摸索。
> **机器信息在 `ops/machines.json`，这里不写 IP。**

## 一、链路

```
         ┌──────────────┐   版本控制   ┌──────────────┐
         │   本地仓库    │ ◀──────────▶ │    远程仓库   │
         └───┬──────▲───┘
             │      │  同轮写回 + 校验（必须）
             ▼      │
        ┌────────────────┐   部署    ┌───────────────────┐
        │  构建 / 打包环境 │ ────────▶ │  测试机（主战场）  │
        └────────────────┘  ◀─ 终端 ─ └───────────────────┘
```

| 角色 | 在真机上干什么 | 用什么通道 |
|---|---|---|
| **开发者** | 改代码 → 构建 → 部署 → 验证 → 同轮写回仓库 | `<部署脚本 / 上传页 / 终端>` |
| **审查者** | 复核开发交的东西：独立跑自检、读码、核实测数字 | `<干净环境跑构建与自检>` + 终端读日志 |
| **监督者** | 盘查问题、定根因 | 终端 + 读仓库 |

`<如果有不需要密码就能进的终端，写在这儿并说明它为什么不算越过安全红线——`
`否则每个角色都会为了看一行日志去麻烦需求方（铁律 5）。>`

## 一之二、调真机用哪个浏览器

🔴 **调私网里的真机，走「需求方自己的浏览器 + 扩展」那条通道，别用 AI 自带的浏览器窗口**：
自带窗口对**私网地址往往只放行第一次文档加载**，此后页面发出的子请求会被客户端策略全部拦掉
（实测形状：登录接口连打 7 次、`GET /` 与 `…/me` 全被拦），于是**页面天生登不进去、也调不了任何接口**——
排查时极容易误判成「机器坏了」。它通常还是**独立 profile**，不继承需求方的登录态。

**这一段要填三件**：①本项目用哪条通道调真机；②它不通时的备选（「跑命令 / 推文件 / 取文件」各走哪个接口、各是什么身份）；③每条怎么验证它通了。

## 二、构建 / 测试环境怎么用

```
<打包命令>
<在干净环境里解包、构建、跑测试与自检的命令>
```

**注意测试里的相对路径**：如果测试代码用 `../../` 这类相对路径读仓库里的文件，
解包后的目录层级必须和仓库里一致，否则那些测试会读不到文件。
**读不到文件时要 FAIL 而不是 PASS**——「悄悄不跑」比「跑出错」更难发现。

## 三、部署脚本

**部署脚本一律放 `ops/scripts/`，调用时带上路径**（`powershell -File ops\scripts\<名>.ps1`）。
🔴 **仓库根不放任何脚本**——`ai/rules/layout.md` §一 的顶层清单里没有脚本的位置，
「一件东西只有一个家」。**这里原来教人在根上建薄壳，和 §一 直接打架**：
有项目照着做真长出了四个 `.ps1`（提交号在那个项目自己的记录里），是开发席-16 顺着需求方的疑问查出来的。
省下的那点打字，换来的是根目录被开一个口子，下一个人会拿它放别的。

**脚本里不许写死路径和 IP**：路径用 `ops/paths.ps1`，机器用 `ops/machines.json`。

**验证一台就够，推更新推全部。** 上测试机**验证**只需在任意一台上验；**推更新**必须推到 `ops/machines.json` 里
**全部 `status=in-use` 且带 `deploy` 角色**的机器——部署脚本默认目标就该是它们，**别手动只推一台**，
否则几台机器版本不一，下一个人在另一台上看到的是旧东西、白查一轮。
守门 `ops/verify/check-paths.sh`。

## 回写本地仓库（写不进去时怎么办）

**仓库是唯一的源**，在别的机器上改完必须同轮写回。写回可能被拒（文件被编辑器或杀毒软件占用）。
**按这个顺序试，不要反复重试同一招：**

1. **正常写回** → 写完逐个 `sha256sum -c` 对账。**没对账 ＝ 没写回。**
2. **被拒 → 用改名法**（占用通常只锁「打开」不锁「改名」）：
   ```
   mv 原文件 原文件.bak && cp 新文件 原文件 && rm 原文件.bak
   ```
3. **改名法也不行 → 换路径**：写到 `tmp/`，在回报里写清「哪个文件没写进去、临时件在哪、要怎么合」。
4. **仍然不行 → 申请权限**，**不要让需求方去跑命令**（铁律 5）。

**三件不许做**：不许反复试同一个失败的方法；不许把「请你跑一下这条命令」当解决方案；
不许只改运行环境不改仓库（运行环境是易变的，仓库才是源）。
