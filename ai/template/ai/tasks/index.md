# 任务索引

> **一任务一文件**，文件名 `T-<四位号>-<五到十字标题>.md`。这里只放一行摘要，**细节点开任务文件**。
> 状态机与模板见 `../rules/workflow.md`。
> **下一个可用任务号：T-0001**（用谁加一，规矩同决策取号）

## 在办（开发者每段开工先看这张表）

| 号 | 标题 | 状态 | 优先级 | 派给 | 关联 |
|---|---|---|---|---|---|
| | | | | | |

**优先级**：P0 现在就做 → P1 本段 → P2 下段 → P3 有空 → P4 记着别忘。
**挂起**必须在「关联」里写清等什么、等到了谁来解锁。等不到就转 `作废`，别挂着装样子。

|---|---|---|---|

> 每一条都要能回答「要他几分钟、解锁什么」。攒够一批一次问完（铁律 5）。

## 已归档

`archive/` 按 `T-####` 原名平铺，**已过满 3 段后**移进去。归档只是从阅读路径里挪走，不删。
找一条：`grep -rl "T-0042" archive/`。

## 三条不许犯

1. **不许开第二本待办。** 同一件事记在两处，状态永远对不上。
2. **不许把状态只写在对话里。** 段与段之间会换会话，对话里的话下一段没人看得到。
3. **不许让任务文件长成事故报告**（上限 150 行）。排查过程写进「开发者回报」的实测小节，长的另开 `claude-outputs/developer/` 下的文件并在这里指路。
