# 分域做法：对外材料（投资人 / 客户 / 开发者）

| 维度 | 做法 | 为什么 |
|---|---|---|
| 格式 | 一份 Markdown 母本，同源出：网页（`index.html`，可直接上传服务器）+ PPT + PDF（逐页排版，参照网页与 PPT，不是网页打印） | 一处改、处处同步 |
| 开头 | 大图标 + 产品名 + 一句定位 | 第一屏就要让人记住是什么 |
| 定位 | 写产品本质，不写第一个场景（第一个场景是起点，不是边界） | 投资人看的是天花板 |
| 写什么 | 能力、应用生态与可想象空间；截图来自正在运行的产品 | 真实截图比效果图可信 |
| 不写什么 | 内部版本区别；「什么还没做」；外部竞品链接；**没有来源的市场数字**（要数字另出一份，写清口径与来源） | 一个站不住的数字会让整份材料失信 |
| 视觉 | 用正在用的 logo 与图标（先问是哪一版）；背景与品牌一致 | 材料和产品要是同一个东西 |
| 网页 | 独立 HTML 自带 `<!doctype html>` 与 `<meta charset="utf-8">`（否则上传服务器后乱码）；面向国内访问不引境外字体服务；正文用压缩图，点击放大看原图 | 加载快，细节又看得清 |
| PPT | 生成时校验：连线高度不能为负、图片用 baseline JPEG（渐进式 JPEG 在部分 PowerPoint 显示空白） | 这两个坑会让 PowerPoint 报「内容有问题」 |
