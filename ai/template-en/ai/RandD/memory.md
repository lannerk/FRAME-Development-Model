# R&D memory — things you only need while researching, but need every time

> **Only the Researcher writes it; cap 80 lines.** The format is **identical to `ai/memory.md`** — seven kinds · each with "verified when" ·
> **append-only** · 🔴 **never the credential itself** (record only "which token · where to find it · which box to paste it into").
> It is **line-level and cross-topic**: you take it to the next topic. When it is full, move whole blocks into the topic's `notes/` and leave one pointer line.

🔴 **Cross-topic facts that belong to the whole project** (the Requester's preferences and red lines, environment quirks) **do not go here** —
`ai/memory.md` is **read-only** for the Researcher; mail the Supervisor to record them there and leave one pointer line here.
