# `drafts/` — claims (how we think it should be done), not settled yet

> `notes/` records **findings** (what the world looks like); this records **claims** (what we intend to do). The two are never mixed.
> 🔴 **A draft never goes into `ai/specs/`** — that directory means "settled = required reading before you start", and a draft there makes development build something nobody agreed to.
> At convergence the drafts are finalized here; at graduation the **Supervisor** migrates them into `ai/specs/` and registers them.

| File | What it is | Status |
|---|---|---|
| `<name>.md` | `<one line>` | `draft / final / migrated to ai/specs/<name>.md` |
